SePay Integration

The SePay Integration Module for Odoo enables instant payment authentication via SePay's payment webhook. Automatic payment QR generation, transaction history recording, etc.

  • User Guides

Features

Dynamic QR code generation
Generate dynamic QR code based on sale order / invoice information.
Automatic Payment Transaction Processing
Automatic payment transaction processing via webhook
Webhook Payment Integration
Record instant payments via webhook from SePay.
Support QR code on website
Support QR code generation for your customers on the website.

III. QR code configuration

Step 1: Add a payment QR-code to your invoices

Navigate: Settings/Accounting/Customer Payments/Active QR Code checkbox

Step 2: Add a bank account to contact of the your company

Navigate: Contacts/Choose your company/Accounting Tab

Warning

The bank account information of the QR code on the Website or POS will take the last line in the bank account list.

IV. Use QR code on invoice

Step 1: Choose Recipient Bank & Payment QR-code

Navigate to your invoice

  • Recipient Bank: The bank account receiving money
  • Payment QR-code: The QR code type used for invoices

QR code will appear on customer portal and invoice report

V. Use QR code on website

Step 1: After the customer purchases and checkout

Choose SePay Payment Method and press button [Pay now]

Your customer will then see a QR code on the screen.

Your customer will scan the QR code and pay for the order. When the payment is successful, the system will record the transaction status and return it to the customer.

The payment transaction record on the backend
